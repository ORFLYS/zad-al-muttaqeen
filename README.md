## 📖 حول التطبيق (About)

تطبيق **زاد المتقين** صُمم ليكون دليلاً إسلامياً شاملاً ودقيقاً يجمع بين رصانة الحسابات الشرعية وجمال التصميم وسهولة الاستخدام. يتيح للمؤمنين في شتى بقاع العالم متابعة أوقات الصلاة والعبادات بدقة متناهية بالاعتماد على الموقع الجغرافي (GPS) أو الاختيار اليدوي، بالإضافة إلى القرآن الكريم كاملاً، والتقويم الهجري الشيعي، ومكتبة غنية بالأدعية والزيارات المأثورة.

---

## ✨ المميزات الرئيسية (Key Features)

- **🕌 مواقيت الصلاة الدقيقة:** احتساب شرعي فقهي دقيق لأوقات الصلوات اليومية وفضيلتها ومنتصف الليل الشرعي مع تحديد تلقائي للموقع بالـ GPS.
- **📢 أذان وتنبيهات مخصصة:** منبه أذان دقيق بصوت نقي وتنبيهات مسبقة للصلوات.
- **📖 القرآن الكريم كاملاً:** رسم عثماني واضح مع إمكانية البحث المتقدم وحفظ العلامات المرجعية.
- **📅 التقويم الهجري والمناسبات:** استعراض تاريخي مفصل لمواليد ووفيات المعصومين (عليهم السلام) وأعمال الشهور والأيام.
- **🤲 موسوعة الأدعية والزيارات:** كنز من الأدعية المشهورة، الزيارات المعتبرة، المناجاة، وتعقيبات الصلوات.
- **🧭 بوصلة القبلة:** تحديد اتجاه الكعبة المشرفة بدقة فائقة مع مستشعر البوصلة الجيروسكوبي.
- **📿 السبحة الإلكترونية والأذكار:** عداد تسبيح تفاعلي يدعم حساس الاقتراب والاهتزاز، مع أوراد الأيام والأذكار اليومية.
- **📱 يعمل دون اتصال (Offline):** إمكانية الوصول إلى كافة النصوص الدينية والمواقيت المحفوظة دون الحاجة لشبكة إنترنت.

## 🛠️ البنية التقنية (Tech Stack)

- **Framework:** Flutter & Dart
- **State Management:** Provider

- **Audio & Media:** Just Audio

## 🚀 البدء والتشغيل (Getting Started)

### المتطلبات (Prerequisites)
- تثبيت [Flutter SDK](https://flutter.dev/docs/get-started/install) (الإصدار 3.27 أو أحدث).
- Android Studio / VS Code مع إضافات Dart و Flutter.
- نظام Android 7.0 أو أحدث على جهاز الاختبار.

### خطوات التثبيت (Installation)

1. استنساخ المستودع:
```bash
git clone https://github.com/USERNAME/zad-al-muttaqeen.git
cd zad-al-muttaqeen
```

2. جلب الحزم والمكتبات:
```bash
flutter pub get
```

3. تشغيل التطبيق في وضع التطوير:
```bash
flutter run
```

4. بناء حزمة الإنتاج (Release Bundle):
```bash
flutter build appbundle --release
```
